Deploy contínuo no ar

Esta página é o artefato de CD do laboratório: publicada automaticamente no GitHub Pages depois que o CI (lint, testes, coverage e build Docker) passa na main.

github-pages · deploy automático

O que este lab cobre

O aplicativo de apoio é só uma calculadora Python. O produto é o pipeline.

  • CI com matrix (Python 3.11/3.12 + Windows)
  • Coverage gate, artifacts e reusable workflow
  • CD separado com environment github-pages
  • Security (pip-audit + CodeQL) e Dependabot
  • Release por tag v*

Como validar o fluxo

Edite site/index.html ou o código Python, faça push na main e acompanhe a aba Actions. Se o CI falhar, esta página não atualiza.
